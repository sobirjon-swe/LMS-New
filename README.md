# LMS-New

AIS HKTB uchun PreSkool demosi va to‘rtta tanlangan skrinshot asosida tayyorlangan mustaqil mahalliy maket.

Brauzerda [index.html](index.html) faylini oching. Yuqori o‘ngdagi profil tugmasi orqali 12 rolni almashtirish mumkin. O‘qituvchi sahifasida jadval, davomat jurnali, topshiriqlar, guruhlar natijalari va guruh kartalarini sinab ko‘ring. Muassasa administratori ekranida tezkor amallar, taqsimot, natijalar va xarita bor. UPVK va Oliy rahbariyat ekranlarida muassasa bo‘yicha ko‘rish mavjud.

Ma’lumotlar namunaviy. Davomat va murojaat amallari joriy brauzer sahifasida sinov uchun ishlaydi. Sahifa qayta yuklansa, o‘zgarishlar tiklanmaydi. Ishlayotgan LMS ma’lumotlari, hisoblar va backend bu papkaga ko‘chirilmagan.
